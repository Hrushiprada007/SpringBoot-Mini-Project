# SpringBoot-Mini-Project
A beginner-friendly Spring Boot mini project demonstrating REST API development, CRUD operations, Spring Data JPA, Hibernate, and MySQL database integration.
# Employee Management System

This is my first Spring Boot mini project, developed to understand the fundamentals of Spring Boot and backend development.

### Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- REST API
- Maven

### Features
- Add employee
- View employee details
- Update employee
- Delete employee
- MySQL database integration

### Concepts Learned
- Spring Boot project structure
- Dependency Injection
- REST APIs
- CRUD operations
- JPA and Hibernate
- Repository layer
- Database connectivity
